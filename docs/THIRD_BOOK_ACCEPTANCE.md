材料：`tests/fixtures/nandi/source.txt` 与人工审阅过的 `extract.json`。测试在临时目录制作数据包，不把未打磨的草稿放入玩家书架。

`python tests/test_generation.py` 覆盖：

- 原文 → 本地启发式 extract → 可玩包；机器报告标明草稿身份。
- 审阅 extract → 可玩包；两条不同选择路线均走到结局，四件定数均发生，延迟后果队列结清，最终数值分叉。
- 模拟文本 API 的长稿分段、结构笔记合并、逐场与结局改写；中途失败后续跑，已完成步骤不重复调用。
- 原文连续 28 字以上重合会被报告；`--strict` 有阻断项时返回退出码 2，同时保留包和报告供修改。

当前离线脚手架报告：**5 个阻断项、19 个提醒**。阻断项都是冲突场景的脚手架说明文字；提醒包括缺少对白、选项措辞与代价组合重复。它能游玩，但不应作为文学成品发布。

模拟模型改写后，结构校验通过，质量机检剩 **0 个阻断项、1 个提醒**（冲突场景代价组合重复）。这是对代码契约和续跑机制的验证，**不是**真实模型文案的质量证明。真实文本 API 尚未配置 Key，后续需要逐幕人工审阅。
