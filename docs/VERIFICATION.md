# 三大防线验证结果

对应意图描述中的三个失败模式。测试：`python tests/test_engine.py`（13 项，全过）。

**扩充后（36 场景 / 13 结局 / 18 人）复测**：定数仍全部必现；双线结局分叉（沟口记得你 / 把妹妹的路照亮的人）；延迟后果队列收尾清零；小世界冲突标签覆盖土地、彩礼、人情、宗族、穷邻、手艺、城里、妹妹。

---

## 防线一：历史不转弯，但选择有后果

**做法**
- 8 个 `canon_events` 固定回合触发，与选项无关
- 每条定数至少 2 条**更早**的风声/物价/人际线索（校验器强制）
- 选项改的是：钱/面子/硬气/温度/关系/旗标/记忆，不改定数

**证据**
- `test_canon_flags_always_set`：任意跑法下量地、订婚、病重、回村、催彩礼、去世、撤并、年关全部发生
- `test_different_choices_same_canon`：偏心软线 vs 偏硬气线定数旗标相同，但 `s_open_home` 选择、李建国关系、金钱不同
- `test_canon_have_early_rumors`：线索 turn < 事件 turn

**试玩对照**
| | A 心软线 | B 硬气线 |
|--|--|--|
| 定数 | 全部发生 | 全部发生 |
| 结局 | `end_li_family` 沟口记得你 | `end_sister_guardian` 把妹妹的路照亮的人 |
| 小雨关系 | 高 | 更高 |
| 李建国关系 | 高 | 分叉 |

玩家可以准备（听风声、备钱、站队），不能把李老栓救活、不能阻止撤并、不能取消订婚。

## 防线二：小世界有事可做

**做法**
- 冲突源 6 个：土地、彩礼、人情债、孤老照应、撤并去留、风声体面
- 时间稀缺：多日只能做一件事（`pick_and_run`）
- 场景标签含：土地/彩礼/人情/妹妹/离开/照应/丧事/面子

**证据**
- `test_conflict_sources_present`
- `test_choices_are_genuine`：同场景选项效果指纹不得重复
- 19 个场景覆盖立秋到大寒，无「拯救世界」选项

**试玩感受**
- 量地那天必须站位：讲理 / 让半步 / 沉默，三条都疼
- 彩礼谈判：砸锅卖铁撑面子 / 砍价保妹妹 / 拒亲硬扛
- 同一天可能：沟口病人 vs 席面人情 vs 自家地，顾此失彼

---

## 防线三：延迟后果会回来

**做法**
- `hooks.delay` 2–12 回合后经 `fire_pending` 结算
- 回响写成**具体的人**：谁记账、谁传话、谁在白事上认人、谁后来开门
- 结局用关系/旗标/记忆累积，不只看最后一幕

**证据**
- `test_hooks_fire_later`：queue 入队 → 未到期不结算 → 到期应用
- `test_playthrough_has_delayed_lines`：完整跑法台本含【迟来的后果】
- `test_relationship_remembers`：关心妹妹的线，小雨关系 ≥ 60

**试玩里的回响样例**
1. 早期给李老栓挑水 → 病重时人记得 → 去世后李建国「认人」→ 结局《沟口记得你》
2. 开局先问小雨 → 数回合后她敢顶娘说想念书 → 彩礼谈判更难也让步
3. 席面厚随礼 → 当场有光，后头彩礼现金更紧
4. 拒一万八 → 村里炸开、娘不出门、妹妹继续念书、三叔骂完又认你

## 附：正确废话 / 空心化检查

- 人物有 speech_style 与例句；对白短、带刺、有口癖，不是百科
- 选项是取舍不是善恶题（两个都想要 / 两个都不想失去）
- 校验器拦：效果完全相同的假选择、未知引用、定数无线索、结局无 epithet
